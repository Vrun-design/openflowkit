The current roadmap and implementation status are maintained in one place:
[the repository documentation index](https://github.com/Vrun-design/openflowkit/blob/main/docs/README.md).

That index links the product requirements, external-agent contract, interaction
specification, technical design, delivery sequence, and recorded implementation
evidence. It also separates later product ideas from current release requirements.

This public page does not maintain a second priority list. Planned capabilities
must not be interpreted as already shipped. Feature guides describe their own
workflows; consult the implementation record for v2 progress.
